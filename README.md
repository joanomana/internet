
# 🌐 Proyecto Interactivo - Enseña lo que Aprendes: ¿Cómo Funciona el Internet?

¡Bienvenido a nuestro recurso interactivo educativo! Este proyecto fue desarrollado como parte de una entrega académica para el *Campus de Programadores* con el objetivo de enseñar de manera clara, dinámica e interactiva cómo funciona el Internet, usando **HTML**, **CSS** , **JavaScript nativo**, 

---

## 📚 Descripción

Este recurso explica de forma visual y didáctica tres conceptos fundamentales del funcionamiento del Internet:

1. **¿Qué es una API?**
2. **¿Qué es Internet y la Web?**
3. **Protocolos HTTP y TCP/IP**

Cada sección está diseñada como una **experiencia interactiva**, con ejemplos prácticos, analogías visuales y botones interactivos que permiten al usuario entender conceptos complejos de forma sencilla.

---

## 🖥️ Tecnologías Utilizadas

- Git y GitHub (colaboración en equipo)

- Sweetalert2

---

## 🚀 Funcionalidades

- Interfaz amigable y visualmente atractiva
- **Explicación con animaciones** de cómo funciona una API usando la analogía de un restaurante
- Explicaciones visuales sobre la diferencia entre Internet y Web
- Diagrama animado de cómo funcionan los protocolos **HTTP y TCP/IP**
- Botones para activar animaciones y cambiar dinámicamente el contenido
- Compatible con pantallas móviles, tablets y escritorio
